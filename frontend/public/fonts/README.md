# Google Sans Flex

Pixel Relay requests a locally installed, licensed copy of Product Sans first.
Because Product Sans is not distributed as an open-source webfont,
`google-sans-flex-latin.woff2` is retained only as the bundled rendering
fallback for clients that do not have Product Sans installed. The fallback is
the Latin variable-font subset served by Google Fonts and supports weights
100–1000.

- Family metadata: https://fonts.google.com/metadata/fonts/Google%20Sans%20Flex
- Font source: https://fonts.gstatic.com/
